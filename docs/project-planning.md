# Expense Tracker & Budget Manager – Project Planning

## 1. Project Title
Expense Tracker & Budget Manager

## 2. Problem Statement
Many individuals face difficulties managing their finances due to manual or improper record keeping. Users need a simple system to record income and expenses, manage budgets, and monitor spending.

## 3. Project Objective
To develop a web-based system that helps users record income and expenses, manage monthly budgets, and monitor their spending.

## 4. Target Users / Stakeholders

### Administrator
- Manages users, categories, reports, and settings.

### Registered User
- Manages personal transactions.
- Creates budgets.
- Views reports.
- Updates profile.

## 5. Core Modules
1. User Management
2. Category Management
3. Expense Management
4. Income Management
5. Budget Management
6. Reports & Dashboard

## 6. Project Scope

### Included Features
- User registration and login
- Income and expense management
- Category management
- Budget management
- Transaction history
- Dashboard and reports

### Excluded Features
- Live bank integration
- Online payment gateway
- Investment management
- Cryptocurrency tracking
- Tax calculations
- Dedicated mobile application

## 7. Functional Requirements
- User registration and login
- Manage income and expenses
- Manage categories
- Create and manage budgets
- View transaction history
- Generate financial reports
- View dashboard summaries

## 8. Non-Functional Requirements
- Security
- Performance
- Usability
- Reliability
- Maintainability
- Scalability

## 9. Expected Outcome
The system will provide users with a centralized platform to manage income, expenses, budgets, and financial information efficiently.
